Internship Scam Detector 🔍

A simple web-based project that helps students identify potentially fake or suspicious internship offers.

📌 About the Project

Nowadays, many fake internship advertisements promise free training, certificates, or internships and later ask students to pay unexpected fees.

The Internship Scam Detector is designed to check internship details and identify common scam indicators.

🚀 Features

- Check internship offers for suspicious signs
- Detect fee/payment-related scam indicators
- Identify suspicious internship claims
- Simple and user-friendly interface
- Instant result with a basic risk indication

🛠️ Technologies Used

- HTML
- CSS
- JavaScript

▶️ How to Run

1. Download or clone this repository.
2. Open the project folder.
3. Open "index.html" in any web browser.
4. Enter the internship details.
5. Click the check/analyze button to see the result.

🎯 Purpose

This project is created to help students become more aware of potentially fraudulent internship offers and recognize common warning signs before making payments or sharing personal information.

⚠️ Disclaimer

This tool is intended for educational and awareness purposes only. The result does not guarantee that an internship is genuine or fraudulent. Users should independently verify the company, internship provider, contact details, and payment requirements.
